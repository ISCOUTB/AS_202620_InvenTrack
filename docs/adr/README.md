# Architecture Decision Records — InvenTrack

Aquí se documentan las decisiones arquitectónicas del proyecto (ADR),
siguiendo el modelo de trazabilidad Aspecto → Requisito → C4 → ADR →
Código → Pruebas → Evidencia.

La decisión inicial está registrada en
[`0001-estilo-arquitectonico.md`](0001-estilo-arquitectonico.md). Define un
Monolito Modular con Hexagonal por módulo. Sigue pendiente, por ejemplo, la
estrategia de control de concurrencia para el aspecto "Consistencia de datos" (ver
[`docs/arc42/arc42-template-EN.md`](../arc42/arc42-template-EN.md),
sección Quality Requirements, escenarios ESC-01 y ESC-02, y la sección
"Trade-offs y tensiones identificadas").
