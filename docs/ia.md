# Uso de IA en el Proyecto

Este documento registra el uso de herramientas de inteligencia artificial durante el desarrollo del proyecto, con fines de transparencia académica. Para cada uso se registra para qué se usó, qué herramienta, qué se aceptó y **qué se rechazó y por qué** — esta última columna es la que se revisa primero, porque es la que muestra el criterio propio del equipo y la prevención activa de la erosión arquitectónica.

## Herramientas utilizadas

- **Claude** (Anthropic)
- **ChatGPT / Gemini** (OpenAI / Google)
- **GitHub Copilot** (Microsoft)

## Criterio del equipo sobre el uso de IA y Control de Erosión

El equipo utiliza la inteligencia artificial como un copiloto de desarrollo acelerado, pero mantiene un control estricto sobre la integridad del código y la arquitectura del sistema:

1. **Cero Erosión de Dependencias:** Toda sugerencia de código es filtrada para evitar la adición no autorizada de paquetes de terceros en `requirements.txt` que comprometan la restricción C5 o introduzcan vulnerabilidades.
2. **Respeto a los Límites de Contexto:** Se verifica continuamente que el código autogenerado respete la arquitectura hexagonal y el aislamiento de módulos definido desde la Semana 6.
3. **Verificación por Defecto / Mutación:** Ninguna función autogenerada se da por correcta sin una prueba unitaria que garantice su fallo cuando el algoritmo o regla de negocio se rompe intencionalmente.
